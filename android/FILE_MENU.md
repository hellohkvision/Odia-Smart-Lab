# Board file menu

- New creates a blank board after confirmation and keeps one device-local recovery copy.
- Save keeps the editable board in app storage. Save as offers an editable JSON file (all pages), PDF (all pages, up to 50 and 16 MiB encoded) or PNG (current page). PDF pages are images, not editable strokes.
- Open and Import read compatible board JSON files. Recover previous restores the last recovery copy.
- Export saves the current board as a PNG image using the Android file picker.
- Cloud Storage uses installed Android document providers through Open or Save to cloud; the save format can be selected before choosing the provider. It is not automatic cloud sync.
- Template and Settings open the existing board style/background controls.
- Send Email opens Android's share chooser with an image. Choose an email app and send it yourself.
- The separate ସାଥୀ button opens the existing activity menu. Menu, ସାଥୀ, Exit, and Share remain separate on the left.

Local app storage can be cleared. For a backup, use Save as and keep the JSON file somewhere safe. An incompatible or oversized import is rejected. File picker and sharing availability depend on installed Android apps.
